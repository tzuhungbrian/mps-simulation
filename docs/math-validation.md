# MVP1 數值核心與驗證

## 範圍與資料邊界

`src/core/simulation.ts` 是不依賴 DOM、React、WebGL 或外部服務的純數值流程：

```text
SimulationConfig → generateCaptures → decodeThreeStep → unwrapRows
                         └ referencePhase ───────────→ evaluatePhase
```

- `referencePhase` 是合成資料的評估答案，**只供評估**。
- 解碼器只接收三張強度影像、調制度門檻與可選的裁切遮罩；不接收真值、頻率或初始相位。
- 展相位只接收包裹相位、有效遮罩與列寬；不讀真值，也不補上未知的整數條紋階數。
- 測試將 `referencePhase` 改成錯誤常數後，解碼與展相位結果完全不變，只有評估誤差改變。
- 輸入影像與設定不被修改；每次執行配置自己的隨機序列與輸出陣列。

## 1. 合成擷取模型

令影像寬、高為 \(W,H\)，\(x=0,\ldots,W-1\)，頻率 \(f\) 表示整個水平範圍內的週期數：

\[
\phi(x)=2\pi f\frac{x}{W-1}+\phi_0.
\]

理想相位沿垂直方向重複。三個相移依序為

\[
\delta_1=0,\qquad\delta_2=2\pi/3,\qquad\delta_3=4\pi/3.
\]

\[
I_k(x,y)=\operatorname{clamp}_{[0,1]}
\left(A+B\cos(\phi(x)+\delta_k)+\sigma Z_{k,x,y}\right),
\qquad Z_{k,x,y}\sim\mathcal N(0,1).
\]

`mean` 為 \(A\)，`amplitude` 為 \(B\)，`noiseSigma` 為強度雜訊標準差 \(\sigma\)，不是相位雜訊標準差。Mulberry32 產生固定種子的均勻偽隨機序列，Box–Muller 轉換產生 Gaussian 樣本。每個像素、每張影像各自抽樣；不是把同一張雜訊複製到三張影像或所有列。這不是密碼學隨機來源。

只要任一張影像在某像素的未裁切強度 \(\leq0\) 或 \(\geq1\)，該像素的 `clipped` 即為 1；恰好落在 0 或 1 也視為邊界裁切。

## 2. 三步相移反解

以 \(I_1,I_2,I_3\) 對應上述正向相移次序：

\[
D=2I_1-I_2-I_3=3B\cos\phi,
\]

\[
N=\sqrt3(I_3-I_2)=3B\sin\phi.
\]

因此

\[
\hat A=\frac{I_1+I_2+I_3}{3},\qquad
\hat B=\frac{\sqrt{N^2+D^2}}{3},\qquad
\phi_w=\operatorname{wrap}_{[-\pi,\pi)}(\operatorname{atan2}(N,D)).
\]

注意分子使用 **\(I_3-I_2\)**；反過來會使相位符號顛倒。`atan2` 能區分四個象限；不能改用單參數 `atan(N/D)`。正 \(\pi\) 統一表示為負 \(\pi\)。

下列任一情況會令 `valid=0` 且 `wrapped=NaN`：

- \(\hat B\leq\text{minModulation}\)，包含等號。
- 可選裁切遮罩標為非零。
- 強度或求得的平均值、調制度不是有限數。

平均值與調制度保留作診斷；無效像素不能被當成零相位。直接呼叫解碼器處理外部影像時，呼叫端必須提供正確的裁切遮罩，才能套用裁切拒絕規則；不傳遮罩不會自動推斷裁切。影像與遮罩長度不一致會丟出 `RangeError`。

## 3. 逐列相對展相位

每個有效連續區段的第一個值保留原包裹相位；後續以

\[
\phi_u[i]=\phi_u[i-1]+\operatorname{wrap}_{[-\pi,\pi)}
\bigl(\phi_w[i]-\phi_w[i-1]\bigr)
\]

累積最短相位差。新列、無效像素或非有限相位都會重設錨點，無效位置輸出 `NaN`。**不跨越缺口，也不跨列延續條紋階數。**

這只能恢復各區段內的相對連續性，結果仍有未知的 \(2\pi m\) 偏移。例：真實起點 4 rad 時，第一個展相位仍為 \(4-2\pi\)，不會利用已知的合成設定偷補整數階數。

此方法要求相鄰真實相位差的絕對值小於 \(\pi\)。設定驗證強制

\[
f<\frac{W-1}{2},
\]

並拒絕 Nyquist 等號。然而這只是無雜訊取樣條件；接近極限時，雜訊仍可能造成週期滑移。圓周 RMSE 也無法揭露整數階數的展相位錯誤。

## 4. 評估

只對遮罩有效、估計相位與參考相位皆有限的像素計算

\[
e_i=\operatorname{wrap}_{[-\pi,\pi)}(\phi_{w,i}-\phi_{\mathrm{ref},i}),
\qquad
\operatorname{RMSE}_{\mathrm{circular}}=
\sqrt{\frac{1}{N_{\mathrm{valid}}}\sum_i e_i^2}.
\]

- RMSE 單位為 rad，不是像素或深度。
- `validRatio = validCount / totalCount`，分母包含所有像素，不只剩下的有效區域。
- 無有效像素時 `rmse=null`，不能回傳看似完美的 0。
- 空陣列的有效率為 0，RMSE 為 `null`。
- 跨越 \(-\pi/\pi\) 分支的相近角度仍只有小誤差，而非約 \(2\pi\)。

## 5. 設定與持久化入口

| 欄位          | 接受範圍（含端點）                   |
| ------------- | ------------------------------------ |
| width         | 整數 32–2048                         |
| height        | 整數 1–1024                          |
| frequency     | 0.25–32，且嚴格滿足上述 Nyquist 條件 |
| phaseOffset   | \(-2\pi\)–\(2\pi\) rad               |
| mean          | 0–1                                  |
| amplitude     | 0–0.5                                |
| noiseSigma    | 0–0.15                               |
| minModulation | 0–0.3                                |
| seed          | 整數 0–4294967295                    |

所有欄位都必須為有限數。`validateConfig(config): void` 在失敗時丟出 `RangeError`。`parseConfig(value: unknown): SimulationConfig` 會驗證完整物件，回傳只包含上述欄位的新副本；不將字串轉為數字，不自動補預設值，額外欄位不保留，無效資料丟出 `RangeError`。呼叫端可自行捕捉例外並決定是否載入預設值。

### 無雜訊基準

使用預設設定（512×192、\(f=6\)、\(\phi_0=0.6\)、\(A=0.5\)、\(B=0.4\)、seed=42）：98,304 個像素全部有效，圓周 RMSE 為 **1.397735073462211×10⁻¹⁵ rad**，屬於浮點運算精度尺度。

### Monte Carlo 相位誤差

未裁切、高訊雜比、獨立同方差強度雜訊下，\(N,D\) 的雜訊變異數皆為 \(6\sigma^2\)，共變異數為零。將 `atan2` 一階線性化並使用 \(N^2+D^2=9B^2\)，得到

\[
\sigma_\phi\approx\sqrt{\frac{2}{3}}\frac{\sigma}{B}.
\]

固定 seed=42，512×128＝65,536 個像素，\(A=0.5\)、\(B=0.25\)、\(f=6\)、\(\phi_0=0.6\)。每個情境皆全部有效：

| 強度雜訊 σ | 預測相位標準差（rad） | 實測圓周 RMSE（rad） | 實測／預測 − 1 |
| ---------: | --------------------: | -------------------: | -------------: |
|      0.005 |        0.016329931619 |       0.016279861220 |       −0.3066% |
|      0.010 |        0.032659863237 |       0.032573434724 |       −0.2646% |
|      0.020 |        0.065319726474 |       0.065253977214 |       −0.1007% |

測試容許預測值 ±3%，不要求隨機樣本恰好等於漸近理論。種子固定，因此可重現且不依賴每次運氣。此結果支援高訊雜比近似，不應外推到弱訊號、裁切或大量無效樣本時。

對 σ=0.01 的各影像殘差，平均值依序約為 0.0000218971、−0.0000249957、0.0000589945；變異數／指定變異數依序為 0.996875、0.996137、0.994810。三對影像的樣本相關係數為 0.005130、−0.000565、0.002467。這些檢查可抓出重複使用同一張雜訊等實作錯誤；有限樣本的低相關不等同數學上的獨立性證明。

## 7. 已知限制

- 目前是三張理想正弦強度影像的相位教學模型，**不是 3D 重建、深度估測或已校正的量測系統**。
- 沒有相機／投影機內外參、幾何三角測量、物體遮蔽、反射率空間變化、gamma、鏡頭失真、散斑、動態場景或實際量化誤差。
- 不估計或校正相移誤差，也不做多頻、Gray code、時間展相位、品質導向展相位或跨區段的絕對階數恢復。
- Gaussian 模型在強度裁切後不再維持原本的分佈；拒絕裁切像素可避免把受破壞的正弦模型當成可靠量測，但有效率會下降。
- 調制度門檻不是低誤差保證。強雜訊可讓原本沒有訊號的像素具有非零估計調制度；有效遮罩只是本 MVP 的規則，不是統計信心區間。
- 圓周 RMSE 不能證明展相位正確，也不能證明任何物理深度準確度；必須與有效率及流程限制一併解讀。
