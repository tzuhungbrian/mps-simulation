# 3D 沙盒量測模型（MVP2：已知校正的理想掃描器）

本里程碑提供可移動三維物體的**正向模擬 → 三張強度影像 → 既有三步相移解碼 → 校正幾何三角測量**。它不是完整相機／投影機校正估計器，也不是 MicroPS 實作。內外參由合成場景直接指定；反算時使用這些已知參數，不會估計或讀取物體表面。

## 資料邊界

- `createWorld(config)` 建立顯示與 CPU 正向模型共用的三角網格定義。
- `captureWorld(config, width=96, height=72)` 以相機像素中心射線取得最近表面，建立三張 `Float64Array` 強度影像。
- `reconstructCaptures({width,height,frames,clipped}, camera, projector)` **只能使用影像、裁切旗標與已知校正**，呼叫 `src/core/simulation.ts` 的真正 `decodeThreeStep`。不輸入網格、真實投影座標、真實深度、遮蔽遮罩、參考相位或條紋級次。
- `runWorldScan` 將正反向串接後，才以 `truthDepth` 評估誤差。其反算呼叫顯式建立四欄位物件，避免評估資料越界。
- `parseWorldConfig(unknown)` 驗證匯入值並回傳只含已知欄位的副本；不將字串轉成數字。`validateWorldConfig(config)` 對無效範圍拋出 `RangeError`。

## 場景與座標

世界座標為右手系，Y 向上，長度使用一致的場景單位。預設物體為中心 `(0,0.75,0)`、半徑 `0.65` 的球，三角網格為 24×16 分段。另提供 1.2×1.2×1.2 立方體，以及 1.5×0.4×1.2、繞 Z 軸旋轉 −0.35 rad 的斜板。地面為 Y=0 的 10×10 平面。所有材質皆為雙面，射線測試與顯示使用相同幾何；Lambert 光照使用變換後的**三角形面法線**。

相機位置 `(-baseline/2,1.8,4)`，投影機位置 `(baseline/2,2.3,3.5)`；兩者皆看向 `(0,0.4,0)`。相機預設垂直視角 45°、96×72；投影機固定垂直視角 55°、160×120。`baseline` 是兩裝置 X 座標差，不是兩個光心間完整的歐氏距離。相機與投影機並非平行整列，反算不依賴簡化的視差公式。

設定範圍：X/Z ∈ [−2,2]，Y ∈ [0.65,2.5]，baseline ∈ [0.4,3]，cameraFov ∈ [30°,75°]，seed 為 uint32 整數，noiseSigma ∈ [0,0.01]；數值必須有限。形狀僅接受 `sphere`、`box`、`ramp`。

## 針孔投影與像素中心

令位置為 C、目標為 T，世界上方向為 Y=(0,1,0)：

```text
f = normalize(T − C)
r = normalize(f × Y)
u = r × f
cx = (W − 1)/2, cy = (H − 1)/2
fy = H / (2 tan(fovY/2)), fx = fy
```

像素索引 `(x,y)` 本身就是像素中心；影像 Y 向下。射線方向為：

```text
d = normalize(f + ((x−cx)/fx) r − ((y−cy)/fy) u)
X(t) = C + t d
```

世界點 X 的投影為：

```text
Z = (X−C) · f
pixelU = cx + fx ((X−C)·r)/Z
pixelV = cy − fy ((X−C)·u)/Z
```

Z≤0 或非有限值均無有效投影。`makePinhole` 會拒絕重合的目標／位置，以及與世界上方向平行、無法決定 right 的視線。投影機有效視錐邊界是 `−0.5 ≤ pixelU < W−0.5` 與 `−0.5 ≤ pixelV < H−0.5`，不是 `[0,W−1]`。

## 正向光照、遮蔽與三張拍攝

每個相機像素僅取最近交點，不做多重表面混合。將交點投影至投影機後檢查視錐，再從投影機向該交點射線測試。只有最近交點距離與目標距離相符（容差 `1e−6 × max(1,距離)`）時才視為可見，因此會出現物體自遮蔽與投影機在地面上的陰影；相機端的遮蔽則由首次最近交點自然決定。

對可照明交點，令外向世界面法線為 n，朝投影機的單位方向為 l：

```text
L = max(0, n·l)
A = 0.12 + 0.4 L
B = 0.36 L
q = (projectorU + 0.5) / projectorWidth       // 0 ≤ q < 1
phi = 2π q − π
I_k = A + B cos(phi + delta_k)
delta = [0, 2π/3, 4π/3]
```

沒有相機交點、超出投影機視錐、被遮蔽或 L=0 時，理想三張影像都為常數 0.12，B=0。零雜訊時，背景、剪影外與陰影皆無有效解碼，不會補上真實深度。極斜的可見面也可能因 B≤0.01 被閾值排除。

`cameraHit` 僅表示相機看見表面。`shadowMask` 表示**相機有交點但投影機不能照明**，包含遮蔽、視錐外與背光；不是只計算幾何投影陰影。背景的 `shadowMask=0`、`truthDepth=NaN`。

可選雜訊對每個像素、每張曝光獨立加入 seed 可重現的 Box–Muller Gaussian 值，之後將強度裁切至 [0,1]。任一曝光達到或越過端點即設定該像素 `clipped=1`；裁切像素不解碼。預設 sigma=0。雜訊也加在背景／陰影上；非零 sigma 下，偶爾會讓無照明像素的雜訊調變超過閾值，成為假陽性，**不會使用真實遮罩偷偷移除**。

## 解碼與單週期的適用限制

解碼器對三張強度計算：

```text
N = √3 (I_2 − I_1)
D = 2 I_0 − I_1 − I_2
wrapped = wrap[-π,π)(atan2(N,D))
B_hat = hypot(N,D)/3
A_hat = (I_0 + I_1 + I_2)/3
```

僅接受有限、未裁切且 `B_hat > 0.01` 的相位。本模型在**整個投影機寬度只放一個完整週期**，且已知交點來自 q∈[0,1) 的視錐，因此可唯一轉回投影機欄座標：

```text
projectorU = projectorWidth (wrapped + π)/(2π) − 0.5
```

這不是一般高頻條紋的絕對相位展開。若改為多個週期，單靠三步相移無法確定條紋整數級次，必須另加 Gray code、多頻或其他真正的消歧資訊；不能以場景真值補級次。目前沒有列方向 spatial unwrap，也沒有參考相位錨定。

## 由投影機欄平面三角測量

投影機欄座標 U 對應通過投影機光心 P 的平面：

```text
n_plane = projector.right − ((U−projector.cx)/projector.fx) projector.forward
n_plane · (X−P) = 0
t = n_plane·(P−C) / (n_plane·d)
X = C + t d
```

近乎平行（相對閾值 1e−12）、非有限交點、相機或投影機後方的點都拒絕。重建另檢查投影機視錐，最後輸出 `depth=(X−C)·camera.forward` 與世界座標 XYZ；無效深度／XYZ 都為 NaN。`phase.valid` 是光度有效性，`reconstruction.valid` 還要求幾何有效，兩者不必相同。

## 評估與已知簡化

- `truthDepth` 與重建深度都是**相機光軸 Z**，不是光心到表面的歐氏距離。
- RMSE 僅使用「重建有效且 truthDepth 有限」的樣本，另報 `evaluatedCount`；沒有可評估樣本時為 null。
- `validRatio = validCount / (width × height)`，分母是**所有相機像素**，不是相機命中數，也不是只算物體。
- `cameraHitCount` 是相機看見的像素數；`occludedCount` 為上述廣義 `shadowMask` 數量。地面也包含在所有影像、重建與統計內。
- 相機／投影機皆為理想針孔，無畸變、校正誤差、逆平方衰減、gamma、間接反射、散焦、鏡面反射或有限曝光。表面反射係數一致，影像不做像素面積積分、抗鋸齒或混合像素建模。
- CPU 正向影像與反算以 Float64 執行；Three.js GPU 的投影 shader、色調映射、深度陰影貼圖與顯示取樣只用於互動視覺呈現，**不讀回 GPU 畫面當成量測輸入**。兩者使用相同網格與基本光照公式，但 GPU 平滑法線／陰影解析度等外觀細節不等同 CPU 面法線／精確射線測試。
- 預設 96×72 是為互動延遲而選的低解析度，不代表感測器精度。`captureWorld` 在 finally 釋放暫時網格與材質；外部顯示用 `createWorld` 的呼叫者需自行呼叫 `dispose()`。釋放的是建立時擁有的原始資源，不會誤釋放呼叫者替換的 shader 材質。

## 可重現驗證

```bash
npm test -- src/sandbox --reporter=verbose --disableConsoleIntercept
```

測試涵蓋整列解析深度 5、非平行姿態、獨立點強度反算、幾何退化、背景／剪影／投影遮蔽、三種物體與移動、雜訊 seed、裁切／非有限輸入、真值竄改與完全移除後反算不變，以及影像相位變動確實改變深度。

預設零雜訊 96×72 的實際基準：總像素 6912，相機命中 4699，有效重建／可評估樣本 3906，未照明命中 790，覆蓋率 0.5651041666666666，光軸深度 RMSE 約 `1.76e−15` 場景單位。這是理想合成模型浮點一致性的檢查，**不是實機精度宣稱**；執行時間由測試當次輸出，不設定跨機器的固定時間門檻。
